## ArkKVM System Images

### Factory Images

Factory images restore the device to factory defaults and erase all user settings and data.

* arkkvm-system-image-v1.img

### OTA Images

OTA images update the operating system and ArkKVM application while preserving user settings and data.


* arkkvm-system-image-ota-091413.img (Mid-Sep 2026)
    Bug Fixes
      - Fixed an issue where text selection could drift when dragging after double-clicking to select text.
      - Fixed an issue introduced in the previous release where an incorrect subnet mask could be assigned in certain network environments, causing ArkKVM to become inaccessible.
    Improvements
      - Improved the UI during WebUI connection.
      - Improved storage usage management for Virtual USB Drive and Virtual Media.
      - Optimized log storage usage to reduce unnecessary space consumption.

* arkkvm-system-image-ota-081410.img (Aug 2026)
